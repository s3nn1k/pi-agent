# Флоу тех. проработки фичи

## Применимость

Подготовка фичи до кода: замысел -> согласованные артефакты. Необходимость проработки
определена до входа (диспетчер/человек) - внутри скилла не решается. Маршрут приходит от
диспетчера по классу (L - полный цикл; M - план, спека по явной потребности; XL -
декомпозиция у диспетчера, каждая фича - свой цикл) или прямым входом: тема, папка фичи
(resume), doc.md. Существующие документы на входе - неполные: доработать или переделать,
не принимать как готовые. Фазы с человеком ведёт этот скилл; роли, раунды и вердикты
субагентов - оркестрация; каноны вида артефактов - doc-canons; подача блоков - show-me.

## Эталон

Фазы с контрактами вход/выход; вход в фазу - по состоянию артефактов (resume), фаза
пройдена, когда состоялся её выход:

```text
вход (тема | папка фичи | doc.md) -> ф1
ф1 интервью      : оценка замысла -> дерево решений; <=3 независимых вопроса за раунд;
                   ответ человека -> пересмотр дерева -> следующие вопросы;
                   выход - существенные решения согласованы однозначно и человек
                   подтвердил достаточность
ф2 doc.md        : черновик по канону вида (пишет воркер оркестрации); папка
                   ~/vaults/work/researches/<feature-slug>/ (нет vault - docs/<slug>/
                   репозитория); выход - черновик, чистый по канону вида
ф3 прогон блоков : содержительные блоки логики - по одному с человеком, следующий после
                   ответа; подача - show-me (поток - псевдокод/call-tree, матрица -
                   таблицей, изменение - diff-шeйпом);
                   выход - каждый блок подтверждён или исправлен -> doc.md финализирован
ф4 plan.md       : по канону вида; оценки - по одной задаче с человеком;
                   выход - план согласован
ф5 tests.md      : из финализированной спеки; один проход; выход - кейсы покрытия
выход            : DoD достигнут -> код-конвейер оркестрации
```

### Конец флоу (DoD)

Флоу закончен, когда одновременно:

- интервью закрыто человеком: существенные решения имеют однозначные ответы, достаточность
  подтверждена;
- doc.md финализирован: ф3 пройден, канон-ревью per-rule зелёное, adversarial замысла на
  L - APPROVED;
- plan.md: оценка каждой задачи подтверждена человеком;
- tests.md выведен (L-комплект), compact.md синхронен с решениями.

Открытое - только явно принятое человеком неблокирующее или вынесенное за скоуп;
блокирующее открытое = флоу не закончен, стоп-вопрос. Сдача: файлы + сводка (решения из
неоднозначных, точки без кейсов).

## Реестр правил

### ф1 интервью

- R-1 Новый вход всегда начинает интервью - решение "всё понятно" принимает человек, не
  агент. Открывает интервью оценка замысла, соразмерная задаче: нужна ли возможность,
  какова цель, чем обоснованы ограничения и выбранное решение, есть ли более простой
  достаточный вариант, что на границах и при отказах, как проверить результат. Оценка -
  активная проверка замысла, не заполненность разделов; её результат - первое дерево
  решений.
- R-2 Существующие документы на входе - материал интервью, не готовый результат: неполные
  или устаревшие - доработать или переделать.
- R-3 Resume (вход - папка фичи): фаза входа - по состоянию артефактов (пройденные фазы не
  повторяются, непройденные не пропускаются); согласованное ранее не пересматривается без
  нового факта.
- R-4 Факты ищи в доступных документах, коде и схемах; недоступный факт - назови источник
  пробела и спроси недостающее. Текущий код не доказывает желаемое поведение.
- R-5 Вопрос задаётся, только если ответ изменит поведение, контракт, данные, доступ,
  гарантии, объём или приёмку; каждому вопросу сопоставлено последствие, без последствия
  вопрос убери.
- R-6 Дерево существенных решений, не плоский чеклист: сначала основания и предпосылки,
  затем зависимые решения. Не более трёх независимых вопросов за раунд; ответы
  пересматривают дерево и открывают следующие; не останавливайся на первом формальном
  ответе, если существенное допущение осталось.
- R-7 Вопрос - с контекстом, реальными альтернативами и их последствиями; при наличии
  оснований - рекомендация; свободный ответ допустим. Необоснованную предпосылку или
  лишнюю сложность оспорь аргументом, но не спорь ради спора. Нерешаемое разговором ("как
  должно выглядеть/вестись") решай артефактом - мини-прототип, макет, спайк: ответ
  человека на артефакт = решение.
- R-8 Согласие - только однозначный ответ; молчание и рекомендация не являются согласием.
  Противоречие предъяви как два несовместимых утверждения с последствиями; не разрешай его
  догадкой.
- R-9 Достаточность закрывает человек: агент предъявляет дерево решений с состояниями
  (согласовано / туман / открыто) и рекомендацию; человек подтверждает или продолжает.
  Существенные решения имеют основания, последствия понятны, скрытые допущения раскрыты.
  Открытый вопрос - блокирующий (стоп-вопрос), явно принятый человеком неблокирующий или
  вынесенный за скоуп. Решение видно, но вопрос ещё не формулируется, - туман: кандидат в
  дереве, не интервью. Глубина - в границах текущей задачи, без обхода всех мыслимых
  ветвей.

### ф2-ф3 документ

- R-10 Интервью само по себе не разрешает файловые изменения: решения встраивает ф2
  воркером по канону вида. Проверка: перечислены изменённые и новые файлы, каждый оправдан
  задачей.
- R-11 Блок прогона самодостаточен для читателя, не открывавшего док: поведение по шагам
  (вход -> исход), термины дока расшифрованы. Подтверждение - по каждому блоку отдельно;
  "так?" на пачку блоков не считается. Развилки в прогон не смешиваются: открытое
  решение - отдельным вопросом по ф1.
- R-12 Расхождение в прогоне: правка блока и повтор только изменённого; все блоки
  подтверждены - doc.md финализирован, возврат к нему только через новое решение человека.

### ф4-ф5 план и кейсы

- R-13 Оценка задачи согласуется одной задачей в сообщении: результат, предложение
  диапазоном, краткое основание, вопрос "оставляем или какая твоя оценка?"; дождись
  ответа, запиши согласованное. Уже согласованное в чате не переспрашивается; нет ответа
  - план не готов к сдаче, оценку самостоятельно не утверждай.
- R-14 ф5 preflight: doc.md финализирован (ф3 пройден; без TODO/"Вопрос / Ответ"; есть
  раздел Термины) - иначе стоп к человеку. Кейсы - один проход без черновых раундов;
  неочевидная точка - вопрос в чат по ф1.

### Полномочия

- R-15 Исходные полномочия задачи сохраняются: поручена реализация - после уточнения
  продолжай без повторного разрешения; поручены план или обсуждение - не начинай
  реализацию.
