# Паттерн "доменный документ": оркестрация написания и ревью

Артефакты фичи - связанные `doc.md` и `plan.md`, а `tests.md` - существующее покрытие,
если оно есть. Каждый вид проверяется по своему reference скилла doc-canons; product и
postmortem остаются отдельными видами. Фазы с человеком (интервью, прогон по блокам,
оценки плана) ведёт флоу тех. проработки - скилл feature-research; здесь - исполнение
ролей. Инварианты - реестр скилла; здесь - маршрут.

## Вход

Тема, контекст, папка или путь к одному из артефактов; если дан путь, сначала прочитай
его. Вызывающая сторона: фичи - флою тех. проработки (начать с темы или заметок нормально

- выходных `doc.md` и `plan.md` на входе может не быть), product и postmortem - свои
  команды. Существующие артефакты фичи прочитай; пару `doc.md` и `plan.md` проверяй после
  воркера. `tests.md` учитывай только если он уже есть: кейсы выпускаются по финальной
  спеке. Product и postmortem не требуют комплекта артефактов фичи.

## Разметка

- Канон-ревью: reviewer с пином doc-canons применяет реестр запрошенного вида; для фичи
  после воркера проверяет каждый существующий reference и согласованность пары; первый
  прогон - fresh, fix-раунды - resume (R-1/R-2).
- Adversarial замысла - на L (R-9), включая стыки артефактов; S/M-правка секции, кейсы
  малой фичи - без него.

## Цикл

1. **Воркер** пишет или обновляет запрошенный артефакт по канону вида. Для фичи -
   связанная пара `doc.md` и `plan.md`; кейсы (`tests.md`) - по финальной спеке. Гейты
   флоу обязательны.
2. **Канон-ревью:** per-rule вердикт по реестру каждого вида и отдельная проверка
   согласованности артефактов. CHANGES_REQUESTED -> fix-задача воркеру (resume) -> повтор;
   cap - R-8.
3. **Adversarial замысла** (L): атака замысла и стыков артефактов по R-9.
   CHANGES_REQUESTED -> решения за человеком (вопрос в чат) -> правка воркером -> повтор
   канон-ревью изменённых секций.
4. **Сдача:** main-осмотр; связанные артефакты и список решений из неоднозначных -
   человеку.

## Границы

- Adversarial не принимает продуктовых решений: замечание - сценарий, выбор - человек.
- Стенограмма интервью - не артефакт; правки живут в документе.
