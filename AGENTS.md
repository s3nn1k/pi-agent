# Main-политика агента

Глобальный контекст main-агента; субагенты его не наследуют.

## Диагностика auth-отказов

При отказе git/glab/API с авторизацией: сначала факты, потом гипотезы. Проверь по порядку:
(1) файл токена на месте и равен vault-источнику; (2) env-переменные сессии непусты; (3)
API-эквивалент напрямую (curl с PRIVATE-TOKEN) - работает ли та же операция минуя упавший
инструмент. Токены не "перезаписываются сами": стор read-only (git-cred-read), ротация -
только руками через vault. Если curl работает, а инструмент нет - проблема в конфиге
инструмента, не в токене.

## Делегирование субагентов

Предпочтай делегирование: список агентов - `subagent({ action: "list" })`.

Делегируй при любом сигнале:

- риск: контракты, деньги, безопасность, миграции - нужен независимый взгляд;
- объём режется на независимые части - параллелизм/изоляция окупаются;
- незнакомый ландшафт или большой объём чтения - scout дешевле, чем тащить в свой
  контекст;
- тяжёлый побочный вывод - большие промежуточные результаты не должны занимать контекст
  main;
- рутина по канону - дешёвый воркер + гейт дешевле дорогого main.

Маршрут любой задачи изменения задаёт скилл task-dispatch (первая проверка - до правок и
до делегирования): без новой логики - XS, main сам; новая логика - класс S+ и конвейер.
Обсуждение без кодового артефакта - без конвейера. Домен не критерий: harness-задачи
(скиллы, скрипты, промпты) - по тем же сигналам.

Решил делегировать - workflow бери из скилла subagent-orchestration (Каталог workflow).

## Гейт репо харнеса

Код/конфиг - `make lint`; установка инструментов - `make init`.

## Артефакты по запросу, не по инициативе

Новые файлы и каталоги - только по явному запросу или репо-конвенции (для них есть место:
`docs/`, `tests/`, доменная папка). "Дай план / разбор / ответ" -> отвечаем в чате
(структурированный текст ок), не плодим `.md`-артефакты и не выдумываем структуру
каталогов. Правки существующего по задаче - норма. WHY: лишний файл = дубликат сказанного
в чате + мёртвый артефакт без владельца; "красивый .md" - не цель.
