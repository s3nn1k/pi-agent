# media-transcript

Локальный стек: **yt-dlp** - скачивание аудио/видео по URL; **wt** - обёртка whisper.cpp
(модель large-v3-turbo): сама конвертирует вход в 16 kHz mono WAV (ffmpeg), чистит свой
tmp, транскрипт печатает в stdout. Скилл даёт медиа/полный транскрипт; сжатие и
интерпретация - забота вызывающего.

## Применимость

- Скачивание медиа по ссылке; транскрипция аудио/видео (URL, прямая ссылка, локальный
  путь); полный транскрипт в файл по запросу.
- НЕ для: веб-поиск и чтение страниц - web-research.

## Эталон

Скелет пайплайна (источник -> yt-dlp -> wt -> результат):

```text
источник
  URL страницы/плеера -> yt-dlp -x -f bestaudio -o "$D/media.%(ext)s"   # tmp: mktemp -d
  локальный путь или прямая ссылка -> путь как есть, yt-dlp и tmp не нужны
-> wt <медиа> -l <lang>                  # транскрипт -> stdout
-> результат: текст в чат | файл: wt <медиа> -otxt -of <база>   # создаст <база>.txt
```

## Механика стека

### Скачивание - yt-dlp

```bash
D="$(mktemp -d)"
yt-dlp -x -f bestaudio -o "$D/media.%(ext)s" <URL>
```

- Рабочая комбинация для транскрипции: `-x` - извлечь аудио, `-f bestaudio` - лучший
  аудиопоток, `-o` - шаблон имени в изолированном tmp (`mktemp -d`). Формат менять только
  под задачу.
- Плейлист: yt-dlp по умолчанию качает всё - до запуска спроси, что брать.

### Транскрипция - wt

```bash
wt <аудио|видео> -l <lang>      # -l auto - автоопределение языка
```

- Контракт: конвертацию, модель (large-v3-turbo) и свой tmp wt берёт на себя; наружу -
  только транскрипт в stdout. Вход - всё, что читает ffmpeg.
- Доп. флаги пробрасываются в whisper-cli; полный транскрипт в файл -
  `wt <медиа> -otxt -of <база>`.
- Шаг долгий: час аудио - минуты. Таймаут вызова ставь с запасом; техвывод whisper в чат
  не тащить.

### Локальные файлы

- Локальный путь или прямая ссылка на файл - без yt-dlp и tmp, путь как есть в wt.
- Выжимку не строить: наружу полный транскрипт как есть.

## Ограничения

- Ошибка yt-dlp (возраст, регион, приватность) - доложи как есть; обход блокировок -
  только по явному запросу.
- Длиннее ~2 часов - предупреди и гони целиком (whisper чанкует сам).
- Свой tmp после себя удалить (`rm -rf "$D"`); исходник пользователя не удалять.
- Нет wt/модели - машина без dotfiles-bootstrap: подскажи
  `~/dotfiles/scripts/bootstrap.sh` (wt сам печатает эту подсказку при отсутствующей
  модели).
