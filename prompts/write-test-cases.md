Напиши тест-кейсы фичи. Спека: **$@**. Если пусто - спроси путь к спеке, не начинай
вслепую. Формат кейсов и каталог охвата - скилл doc-canons; ниже - preflight и маршрут.

## Preflight

1. Прочитай спеку; она обязана быть **финализированной**: `TODO:`/"Вопрос / Ответ" в
   тексте - признак нефинальности (открытые вопросы живут в чате, не в спеке). Нашёл -
   стоп, покажи их мне.
2. В спеке есть раздел **Термины** (кейсы ссылаются на его сущности:
   `P(target=5000, bal=1000)`). Нет - стоп, ко мне: финализация спеки - отдельная задача.
3. Файл кейсов - рядом со спекой (именование и "одна фича - один файл" - канон скилла
   doc-canons). Уже существует - редактируй его, дубликат не плодить.

## Режим соавторства

Сначала перечисли точки фичи (эндпоинт / переход статуса / событие: колбэк, вебхук,
фоновый процесс) и согласуй со мной. Затем кейсы по точкам в формате канона (скилл
doc-canons) -> показать -> правки внести.

## По завершении

Покажи файл + суммаризуй: кейсов по областям каталога охвата (скилл doc-canons), точки
фичи без кейсов.
