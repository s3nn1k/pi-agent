# Разбор инцидента (postmortem)

## Где живёт отчёт

`~/vaults/work/incidents/` (каталога нет - создать). Имя файла - `<YYYY-MM-DD>-<slug>.md`
(дата - начала инцидента; правила отчёта - скилл doc-canons). По инциденту уже есть файл -
редактировать его, дубликат не плодить. Vault'а нет - спроси, куда положить.

## Режим соавторства

1. Факты: таймлайн, ссылки, участники - из контекста сессии; недостающее - спроси, не
   выдумывай.
2. Скелет по канону (скилл doc-canons), незаполненное - плейсхолдеры `<...>` -> показать.
3. Заполнение по разделам -> показать -> правки внести.

## По завершении

Покажи файл + списком: незаполненные плейсхолдеры, action items без ответственного или
срока. Статус разбора - `Draft`; перевод в `Готов`/`Закрыт` - за человеком (канон: скилл
doc-canons).
