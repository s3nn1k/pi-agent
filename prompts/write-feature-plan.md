---

Подготовь фичу к реализации. Вход - **$@**: тема, папка фичи, путь к спеке/заметкам или к
`doc.md` (тогда только кейсы); пусто - спроси. Класс и цикл подготовки - диспетчер скилла
`subagent-orchestration` (паттерн "доменный документ"); S - без подготовки, сразу
реализация задачей текстом.

- Расположение: work-root `~/vaults/work/researches/<feature-slug>/`; нет vault -
  `docs/<feature-slug>/` репозитория. Существующие файлы редактируй, дубликаты и пустые
  заготовки не создавай.
- L с неясным маршрутом (существенные решения не сформулировать сейчас или их больше одной
  сессии интервью): сначала карта маршрута в `plan.md` - frontier-вопросы закрывай
  интервью (`spec-clarification`), не решаемые разговором - прототипом (ответ человека на
  артефакт = решение), внешние факты - исследователем параллельно; туман пуст - `doc.md`
  финализируется, дальше обычный L-цикл.
- Кейсы (L-комплект или отдельный вход `doc.md`): preflight - `doc.md` финализирован (без
  `TODO:`/"Вопрос / Ответ") и с разделом Термины, иначе стоп ко мне; один проход без
  черновых раундов, неочевидная точка - вопрос в чат (`spec-clarification`). M без
  `doc.md` - только план, preflight и кейсы не требуются.
- Сдача: артефакты связаны по общему контракту (`doc.md` + `plan.md` на L, план на M),
  ревью по канону вида пройдено; на L - прогон по блокам `doc.md` с человеком пройден
  (каждый блок подтверждён или исправлен); покажи файлы + сводку (кейсы: точки, покрытие,
  точки без кейсов).
